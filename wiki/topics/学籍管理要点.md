# 学籍管理要点（综合）

权威现行校规：[[学籍管理实施办法-2025]]。部门：[[教务处]]。

## 生命周期

[[入学与注册]] → 学习考核（[[学分绩点]] / [[缓考与重修]]）→ 异动（[[转专业]] / [[转学]] / [[休学与复学]] / [[留级]]）→ [[学籍预警]] → [[毕业结业学位]] 或 [[退学]]

## 一句话数字卡

| 问题 | 现行答案 |
|---|---|
| 本科最长读几年？ | 8 年（创业休学手续齐可再 +2） |
| 专科最长？ | 6 年 |
| 多少学分挂科要留级？ | 学年末必修不合格累计 20 |
| 多少学分可能退学？ | 本科大四前必修不合格 ≥50；专科大三前 ≥40 |
| 转专业几次？ | 仅 1 次 |
| 缓考怎么申请？ | 考前系统申请 + 证明，学院→教务处 |

与 2022 手册冲突一律以本文件为准：[[新旧规定对照]]。
