# 奖助学金体系（综合）

权威现行校规：[[奖助学金管理办法-2025]]。上级细则：[[本专科生国家奖学金评审办法]]、[[湖北省学生资助资金管理办法]]（均 pending-ocr）。

## 结构

```
国家：国家奖学金 / 国家励志奖学金 / 国家助学金
学校：综合奖（和润、校长、优秀学生…）+ 单项奖 + 团体奖
社会：捐赠类按捐赠方要求
```

金额与比例见 [[国家奖学金]]、[[国家励志奖学金]]、[[国家助学金]]、[[学校奖学金]]。

## 学生侧流程（校级）

1. 符合条件者书面申请
2. 二级学院初评、公示、推荐
3. 校评审领导小组审核 → 校长办公会确认
4. 校园网/橱窗公示 ≥5 个工作日
5. 异议 → 5 个工作日内向 [[学生处]] 复议

## 答题提示

- 问「国家奖学金多少钱」→ **10000**（校 2025）；可补充教育部条件（大二起、成绩前 10% 等）。省 2023 文仍写 8000，以校发为准。
- 励志 → **6000**；助学金 → 省标平均 3300、三档 2200/3300/4400，本校分档看当年通知。
- 问能否兼得 → 国家奖与励志不能同获；国家奖/励志可与助学金同获；国家/省市奖学金原则上不兼得；和润/校长/优秀学生取最高。
- 有处分或补考/重修 → 个人校奖学金基本没戏（缓考除外）。
