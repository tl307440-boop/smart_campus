# 学分与绩点

来源: [[学籍管理实施办法-2025]]

## 学分计算

- 理论课：每 16 学时 = 1 学分
- 体育课与独立实验课：每 32 学时 = 1 学分
- 实习/课程设计/论文等实践：每周 1 学分
- 军事理论与技能必修，合格获相应学分

## 绩点系数

| 成绩 | 绩点 |
|---|---|
| 90–100 | 4.0 |
| 85–89 | 3.7 |
| 82–84 | 3.3 |
| 78–81 | 3.0 |
| 75–77 | 2.7 |
| 72–74 | 2.3 |
| 68–71 | 2.0 |
| 64–67 | 1.5 |
| 60–63 | 1.0 |
| <60 | 0 |

课程学分绩点 = 绩点系数 × 学分；平均学分绩点 = Σ学分绩点 / Σ学分。

五级制：优 90–100 / 良 80–89 / 中 70–79 / 合格 60–69 / 不合格 0–59。及格获学分。
