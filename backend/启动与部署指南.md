# 智悦校园 · 启动与部署指南

## 〇、整体架构

前后端已拆开，各自独立部署：

```
浏览器
  │  HTTP + SSE
  ▼
Next.js 前端 (frontend/, 3000)      ← 只管界面与交互
  │  fetch NEXT_PUBLIC_API_BASE
  ▼
FastAPI 接口层 (backend/api.py, 8001)
  │
  ├─ graph_app.py   LangGraph 意图路由与生成
  ├─ knowledge.py   data/ 预载 + 上传文档
  ▼
Redis（会话记忆） + ChromaDB（向量检索） + DeepSeek / Kimi / 智谱
```

`backend/app.py`（Streamlit）作为旧版一体化界面保留，用于对照，不参与新架构。

### 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| POST | `/api/sessions` | 新建会话，返回 thread_id |
| GET | `/api/sessions/{tid}/messages` | 从 Redis 恢复历史消息 |
| POST | `/api/chat` | 提问，SSE 返回 status / delta / done |
| GET | `/api/documents` | 已登记文档列表 |
| POST | `/api/documents` | 上传 txt / pdf |
| DELETE | `/api/documents` | 清空向量库 |

启动接口层：

```powershell
cd backend
python -m uvicorn api:app --reload --port 8001
```

启动前端见 `frontend/README.md`。

## 一、Redis 上下文持久化原理

### 1. 整体架构

```
用户浏览器 (Streamlit)
    │
    ▼
app.py (前端入口)
    │  uuid4() 生成 thread_id
    │
    ▼
graph_app.py (LangGraph 图)
    │  graph.invoke(state, config={thread_id})
    │
    ├─ intent_node: 意图判定
    ├─ retrieve_node: 知识检索
    ├─ generate_node: LLM 生成回答
    │
    ▼
Redis (持久化存储)
    └─ 按 thread_id 存储完整 State 快照
```

### 2. Redis 连接流程

```
首次调用 get_checkpointer()
    │
    ├─ 读取环境变量 REDIS_URL（默认 redis://localhost:6379）
    ├─ 创建 RedisSaver(redis_url)
    ├─ 调用 _checkpointer.setup() 在 Redis 中创建索引结构
    └─ 返回单例对象（后续复用）
```

**代码位置：** `graph_app.py` 第 147-168 行

```python
def get_checkpointer() -> RedisSaver:
    global _checkpointer
    if _checkpointer is None:
        redis_url = os.getenv("REDIS_URL", "redis://localhost:6379")
        _checkpointer = RedisSaver(redis_url)
        _checkpointer.setup()  # 创建 Redis 索引
    return _checkpointer
```

### 3. 每次对话的 State 流转

```
第1轮: 用户说"我是唐亮"
    │
    ├─ invoke(input_state, {thread_id: "a1b2c3d4"})
    │   ├─ intent_node → intent="DIRECT"
    │   ├─ generate_node → final_answer="嗨，唐亮！"
    │   └─ messages = [{user:"我是唐亮"}, {assistant:"嗨，唐亮！"}]
    │
    └─ Redis 自动存储:
        key = checkpoint:a1b2c3d4
        value = {messages: [...], intent: "DIRECT", final_answer: "..."}

第2轮: 用户说"我是谁"
    │
    ├─ invoke(input_state, {thread_id: "a1b2c3d4"})
    │   ├─ Redis 恢复历史 State → state["messages"] 包含第1轮对话
    │   ├─ intent_node → intent="DIRECT"
    │   ├─ generate_node → 看到历史中有"我是唐亮" → 回答"你是唐亮"
    │   └─ messages 追加第2轮
    │
    └─ Redis 更新存储:
        key = checkpoint:a1b2c3d4
        value = {messages: [第1轮..., 第2轮...], ...}
```

### 4. 为什么刷新页面后对话还能保持？

- `thread_id` 存储在 Streamlit 的 `st.session_state` 中
- 只要不关闭浏览器标签页，`st.session_state` 在页面刷新时保持不变
- 同一个 `thread_id` 每次 invoke 都从 Redis 恢复同一份 State
- 所以对话历史自然保持

### 5. 多用户并发隔离

```
用户A → thread_id = "uuid-A" → Redis key: checkpoint:uuid-A → 独立 State
用户B → thread_id = "uuid-B" → Redis key: checkpoint:uuid-B → 独立 State
用户C → thread_id = "uuid-C" → Redis key: checkpoint:uuid-C → 独立 State
```

## 二、启动步骤

### 方式 A：Docker Compose 一键启动（推荐）

1. 启动 Docker Desktop，等待引擎就绪  
2. 确认 `backend\.env` 已填写各 API Key  
3. 在项目根目录执行：

```powershell
docker compose up --build
```

会拉起三个服务：Redis、FastAPI（8001）、Next.js 前端（3000）。浏览器打开 http://localhost:3000 。
Compose 先等 Redis healthcheck 通过再启动接口层；`.env` 固定从 `backend/.env` 加载，不依赖容器工作目录。

想跑旧版 Streamlit 界面（8502）：

```powershell
docker compose --profile legacy up app
```

### 方式 B：本机 Python + Docker Redis

### 步骤 1：安装 Python 依赖

```bash
cd d:\4C_competition\smartcampus\smart_campus
.\venv\Scripts\pip install -r requirements.txt
```

### 步骤 2：启动 Docker Desktop

1. 双击桌面 Docker Desktop 图标
2. 等待任务栏鲸鱼图标变为稳定状态（无红色提示）
3. 验证 Docker 可用：

```powershell
docker --version
# 应输出: Docker version 29.x.x
```

### 步骤 3：启动 Redis（使用 Docker）

**仅 Redis：**

```powershell
docker compose up -d redis
```

或手动：

```powershell
docker run -d -p 6379:6379 --name redis redis/redis-stack:latest
docker exec redis redis-cli ping
# 应输出: PONG
```

### 步骤 4：配置 API Key

编辑 `backend\.env` 文件，填入你的 API Key：

```
deepseek_API_key=sk-你的DeepSeek密钥
deepseek_url=https://api.deepseek.com

kimi_API_key=sk-你的Kimi密钥
kimi_url=https://api.moonshot.cn/v1

zhi_pu_API_KEY=你的智谱AI密钥
```

### 步骤 5：启动接口层与前端

```powershell
# 终端 1：FastAPI
cd smart_campus\backend
python -m uvicorn api:app --reload --port 8001

# 终端 2：Next.js
cd smart_campus\frontend
npm install
npm run dev
```

浏览器打开 http://localhost:3000 。URL 中的 `?tid=` 用于跨刷新对齐 Redis 会话。

旧版 Streamlit 界面仍可单独启动：

```powershell
cd smart_campus\backend
python -m streamlit run app.py
```

## 五、常见问题

### Q: Streamlit 启动报 `ImportError: cannot import name 'RedisSaver'`
**原因：** Redis Stack 没有启动
**解决：** 先执行 `docker start redis`

### Q: Streamlit 页面加载慢
**原因：** VectorDB 初始化需要时间（首次连接智谱 AI）
**解决：** 正常现象，等待几秒即可

### Q: 发送消息后没有回复
**原因：** DeepSeek API Key 过期或余额不足
**解决：** 检查 `backend\.env` 中的 `deepseek_API_key`

### Q: 刷新页面后对话消失了
**原因：** 关闭标签页或丢失了 URL 中的 `tid` 参数  
**解决：** 保持地址栏中的 `?tid=...`；同一 `tid` 会从 Redis 恢复对话历史到界面与模型上下文。
